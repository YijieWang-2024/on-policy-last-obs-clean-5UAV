## Data Policy

Small processed arrays and summaries required to regenerate paper figures are intentionally kept with the code. Heavy checkpoints, TensorBoard event files, generated images, and `scripts/results/` are excluded by `.gitignore` and remain in the historical directory.

The `onpolicy/legacy_analysis/` directory contains exploratory utilities preserved for provenance. It is not part of the main training entry point.

## Important Integrity Notes

1. `extend_ara_curve.py` extends an incomplete ARA curve using a stochastic AR(1) process and a configured final target. Treat the resulting curve as historical post-processing, not as independently observed training episodes.
2. The trajectory and association scripts alter loaded UAV coordinates before plotting. Do not describe those coordinates as raw simulator output without disclosure or regeneration.
3. Run plotting scripts from the `onpolicy` directory because several historical scripts use paths relative to that directory.
4. The saved Fig. 4 arrays (`mappo.npy`, `dcppo.npy`, and `ara_extended.npy`) have shape `(3, 1750)`, so they contain three curves. This does not match the manuscript statement that all results are averaged over five random seeds and must be resolved before making a reproducibility claim.
